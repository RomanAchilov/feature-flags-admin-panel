# AGENTS.md

## Обязательные правила для агента

1. Все новые/изменяемые типы описывай Zod-схемами. Если есть TS-тип — добавь/обнови соответствующую z.object/z.enum схему и используй её для валидации данных/форм.
2. Для любого нового кода пиши тесты (Vitest) и обновляй существующие, если меняется поведение. Минимум: покрыть новые функции/хуки/компоненты проверками успешных кейсов и ошибок.
3. После разработки запускай подряд: `npm run test`, `npm run typecheck` (или `npm run build` если нет отдельного typecheck), `npm run lint` (Biome). Не сдавай работу без прохождения этих шагов или явного описания, почему не запущены.
